# 대학원생을 위한 학술 논문 작성

글로벌 역량 증진 · 이용직 (Yong-Jik Lee, Ph.D.) · 국립창원대학교

저자 PDF(85쪽, 16장)를 그대로 옮긴 웹 전자책입니다. 읽는 방식이 다른 두 판본을 함께 담고 있습니다.

| 판본 | 경로 | 성격 |
|---|---|---|
| 자료형 | `/` | 좌측 목차 고정 · 찾아 읽기 |
| 연재형 | `/read/` | 한 칼럼 세로 읽기 · 1화씩 |

## 구성

- 3부 16장 (Part Ⅰ 학술적 영어 글쓰기와 교육 연구 / Ⅱ 연구 절차별 가이드라인 / Ⅲ 연구 및 학술적 영어 글쓰기 심화)
- 각 장은 도입 질문 → 학습 목표 → 본문 → 성찰 질문 순서
- 참고문헌 40항 · 부록(유학생을 위한 핵심 자료) 30항

## 읽기 기능

읽기 진행바 · 어두운 화면 · 점검목록 저장(브라우저) · ← → 키 이동 · 인쇄용 레이아웃 · 모바일 대응

외부 CDN·폰트·트래커가 없어 오프라인에서도 열립니다.

## 원문 충실성

문장을 추가·삭제·재작성하지 않았습니다. PDF 레이아웃 줄바꿈 복원과 머리말·쪽번호 제거만 수행했으며,
자동 검증으로 **16장 본문 단어 100% 보존**(누락 0, 링크 오류 0)을 확인했습니다.
